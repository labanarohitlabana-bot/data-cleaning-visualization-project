# Data Cleaning & Visualization Project

This project focuses on cleaning, analyzing, and visualizing an Online Retail dataset using Python.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Work
- Loaded and explored the dataset
- Cleaned missing and duplicate data
- Processed and prepared data for analysis
- Performed customer and sales analysis
- Created visualizations to identify useful insights
- Analyzed customer revenue and sales patterns

## Dataset
The project uses an Online Retail dataset containing customer, product, quantity, price, and transaction information.

## Files
- `Online Retail.xlsx` — Dataset
- `Untitled.ipynb` — Data cleaning, analysis and visualization notebook

## Conclusion
The project demonstrates how raw retail data can be cleaned, analyzed, and visualized to extract meaningful business insights.
